EMBERLINE — Foundry Protocol: a 5v5 round-based tactical FPS in three.js. Plant or defuse the Surge Core on an original foundry map, earn money between rounds, buy rifles, SMGs, snipers and grenades, and outplay bot squads with real AI.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser with WebGL 2, click to lock the mouse, and play. WASD to move, mouse to aim, click to fire, R to reload, B for the buy menu, E to plant or defuse the Surge Core, G to throw a grenade, `?demo=1` for an attract mode.
